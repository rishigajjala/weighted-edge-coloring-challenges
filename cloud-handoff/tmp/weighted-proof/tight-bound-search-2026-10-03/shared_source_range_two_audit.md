# Shared-source range-two permutation audit

**Status (2026-10-03): binary theorem proved; arbitrary real weights open.** This note concerns the exact-stock integer bridge for arbitrary links between tiny stars. It proves the range-two statement for source states in `{0,1}^2`, with no restriction on the link graph or number of colors. Actual tiny-leaf loads lie in `[0,1]`, so this does not yet give the required integer coloring bound.

## Exact finite statement

Let `G=(V,E)` be any loopless multigraph of shared sources. Source `e=uv` has exactly `N` labelled states `z_ei=(a_ei,b_ei) in [0,1]^2`. Choose a permutation `pi_e` of `[N]` independently for each source, using the **same** permutation at both endpoints. Set

`L_vc = sum_{e incident to v} z_e,pi_e(c)(v)`.

The proposed bridge is `max_c L_vc-min_c L_vc <= 2` for every `v`, with no restriction on the graph or on the source-state vectors beyond `[0,1]^2`. This would allow private within-star lists to be opposite-sorted afterward, giving total hub-list width at most two. The known width-two/mean-at-most-one chord bound would then give overload at most `N/2` at each hub simultaneously. The unrestricted real-valued bridge remains unproved; the binary case is proved below.

An exact mixed-integer formulation uses `x_eic in {0,1}`. For every source `e`, impose `sum_c x_eic=1` for each state `i` and `sum_i x_eic=1` for each color `c`; for every hub `v` and colors `c,d`, impose

`-2 <= sum_{e incident v} sum_i z_ei(v)(x_eic-x_eid) <= 2`.

Thus infeasibility of this finite system for any input is a genuine counterexample to the bridge. A stronger, separately tested condition replaces pairwise differences with `|L_vc-mu_v|<=1`, where `mu_v=N^{-1}sum_e sum_i z_ei(v)`; that stronger condition is **not** known to be equivalent to range two.

## Theorem: arbitrary asymmetric binary source states

If every source state belongs to `{0,1}^2`, there are source permutations with `|L_vc-L_vd| <= 2` for every hub `v` and colors `c,d`.

**Signed-trail lemma.** Let `H` be any loopless multigraph, allowing an edge to have coefficient zero at one or both endpoints. Give each incidence `(v,e)` a number `eta_ve in {-1,0,1}`, and let `D_v=sum_{e incident v} eta_ve`. If some vertex has `D_v>=3`, there is a set `F` of distinct edges such that negating both endpoint signs on each edge in `F` strictly decreases `sum_v D_v^2`. The same holds for `D_v<=-3` by negating all signs first.

Proof of the lemma: start at a vertex `r` with `D_r>=3` and take an unused edge having sign `+1` at `r`. Traverse to its other endpoint `w`. If its incidence there has sign zero, stop. If it has sign `s in {+1,-1}` and `s D_w>=1`, stop. Otherwise take an unused edge at `w` whose incidence sign is `-s`, and traverse it. Such an edge exists. At a nonroot vertex all earlier completed visits have consumed one positive and one negative incidence; the current incoming sign `s` is unpaired. If `s=+1` and `D_w<=0`, an unused negative incidence remains; if `s=-1` and `D_w>=0`, an unused positive incidence remains. At the root, the initial outgoing positive incidence is additionally unpaired. A return with negative sign cannot stop, but `D_r>=3` guarantees another unused positive incidence. Every step consumes a new edge, so the walk terminates, including when vertices are revisited.

Negate the signs on exactly the traversed edges. At every internal visit the incoming and outgoing signs cancel; repeated internal visits cancel separately. The root's selected-sign sum is `+1`, or `+2` if the walk terminates back at the root with a positive incoming sign. Thus its discrepancy changes from `D_r` to `D_r-2` or `D_r-4`, strictly decreasing its square because `D_r>=3`. At a distinct terminal vertex with sign zero nothing changes. Otherwise its selected-sign sum is `s`, with `s D_w>=1`, so replacing `D_w` by `D_w-2s` does not increase its square. All other discrepancies are unchanged. This proves the lemma.

Now choose source permutations minimizing the finite potential `Phi=sum_{v,c} L_vc^2`. Suppose `L_vc-L_vd>=3` somewhere. Freeze all other colors. For each source `e`, let `eta_ue=z_e,pi_e(c)(u)-z_e,pi_e(d)(u)` and similarly at `v`; these values lie in `{-1,0,1}`. The color difference at each hub is `D_v=sum_e eta_ve`. Apply the signed-trail lemma and swap the two source states assigned to `c,d` on each traversed source. These are valid source permutations. At each hub the two-color sum `L_wc+L_wd` stays fixed, and `L_wc^2+L_wd^2 = ((L_wc+L_wd)^2+D_w^2)/2`. The lemma strictly decreases `Phi`, a contradiction. Swapping the color labels handles a negative gap. Hence all gaps are at most two.

The constant two is sharp: take `N=2` on a triangle and give each edge the states `(1,1),(0,0)`; any assignment of the three active edges to two colors has a vertex with loads `(2,0)`.

**Algorithm.** Start with arbitrary source permutations. Find any hub and color pair with gap at least three, construct the signed trail above, and swap along it. Binary loads make `Phi` integer, and each swap decreases it by at least four: the root's squared color-difference falls by at least eight, while the terminal does not increase it. If there are `m` shared sources, each color load is at most the source degree, so initially `Phi <= N sum_v deg(v)^2 <= 2 N m^2`. Hence at most `N m^2/2` trail swaps occur. Finding a violating pair and trail by direct scans is polynomial in `N,m`; no optimization oracle is needed.

**Common per-hub amplitudes.** The same conclusion holds if, at each hub `v`, all incident source-state coordinates have form `b_ev+a_v t_ei(v)` with `t_ei(v) in {0,1}`, state-independent `b_ev`, and one hub-wide `0<=a_v<=1`. Run the binary algorithm on the `t` values. The sum of baselines is constant across colors, so the real load range is at most `2 a_v <= 2`. The amplitude must be common to all sources at a given hub; arbitrary source-dependent amplitudes are not covered.

## Conditional physical integer transfer for any tiny-star forest

Let a weighted multigraph have heavy edges of weight `>1/2` whose simple support is a matching, and all remaining edges of weight at most `tau<1/2` whose simple support is a vertex-disjoint union of stars. Put `N=bp(G)`. Fix actual `N`-bin local packings and align both endpoints of every heavy pair by physical heavy identity, exactly as in `physical_single_tiny_star_integer_transfer.md`. A pair linking two **different** tiny-star components is a shared source. In each aligned row, its contribution to a component's proposed hub load is the leaf's proposed tiny load if its endpoint is a leaf, or the hub's heavy-edge load if its endpoint is a hub. Both lie in `[0,1]`. Assume these two contributions are in `{0,1}` for every row of every cross-star source. The common-per-hub-amplitude version above may replace this binary assumption.

If `N=0`, there are no physical edges and the assertion below is immediate; assume `N>=1` in the construction.

Then the actual physical weighted chromatic number satisfies

`chi'_w(G) <= ceil(3N/[2(1-tau)])`.

Proof: apply the binary source theorem to the graph whose vertices are tiny-star components and whose edges are cross-star heavy-pair sources. It permutes each whole aligned source list once, keeping both endpoint states and every physical heavy identity together, and gives the shared preliminary hub-load sum width at most two at **every** component. All remaining source lists touch at most one tiny-star component. Their contribution lists have width at most one, except a heavy pair joining two leaves of the same star, whose combined tiny load lies in `[0,2]` and has width at most two. At each component independently, append those private lists one by one by sorting the current aggregate up and the next list down, carrying full physical states. The aggregate width remains at most two. Its mean is at most one because its `N`-row total equals the total physical weight incident at that star's hub, which is at most `N` by the hub's original local packing.

For the width-one claim when a private heavy pair joins a hub to one of its own leaves, its row contribution is the hub heavy weight plus that leaf's proposed tiny load; the leaf's original local bin bounds their sum by one. A heavy pair touching one star and an external vertex is private to that star: its external endpoint has no tiny-edge row constraint. A heavy pair outside every tiny-star component can be assigned to the normal rows arbitrarily after its two endpoint lists are aligned, since it contributes to no tiny-star hub. The binary condition is restrictive when a cross-star heavy pair ends at a hub: a present heavy edge of weight strictly between `1/2` and `1` gives a nonbinary hub coordinate.

Thus the width-two chord bound gives total hub overload at most `N/2` at every star. Each normal row is already feasible at every leaf; delete tiny spoke edges at overloaded hubs until all rows are feasible. At each star the deleted weight is at most `N/2+tau N`. Next Fit recolors the deleted edges of each star in at most `ceil((N/2+tau N)/(1-tau))` additional colors. The star components are vertex-disjoint, so their repair palettes can be overlaid. Together with the original `N` rows this yields the displayed bound. Every physical edge appears once, and the procedure is polynomial in the supplied local packings and physical input. The cross-star binary/amplitude assumption is a restriction on actual aligned local-bin states; arbitrary fractional loads remain open.

## Exact small binary checks

Using SciPy 1.13.1 `milp` with binary `z_ei(v)`, every sampled instance was feasible: 120 instances on `K_5` with `N=3`, 120 on `K_6` with `N=3`, and 80 on `K_5` with `N=4`. States were independently uniform on `{0,1}^2` at each source/state, so these checks include asymmetric endpoint values. For the stronger centered-mean-one system, 100 instances each on `(K_4,N=3)`, `(K_5,N=3)`, `(K_6,N=3)`, and `(K_5,N=4)` were feasible. All solves returned status 0 (optimal/feasible); none timed out or reported infeasibility. The scripts used are `/private/tmp/range2_binary_search.py` and `/private/tmp/centered1_search.py`. These checks preceded the proof; the theorem above covers all finite binary inputs, while sampled feasibility says nothing about the stronger centered statement.

## Why two apparent imports do not settle it

The [weighted matroid equitability theorem](https://arxiv.org/abs/2608.13983) partitions a matroid ground set into bases with range at most the largest weight for **one** weight objective. The present source groups form a partition matroid, but there is one objective for every hub, and each state has up to two nonzero hub weights. The same paper's multirow sparse-matrix result has additive error `2 Delta` for one rounded basis; with `Delta=2` it does not imply simultaneous range two for the entire base partition. Its weighted-car-pooling counterexample has prefix constraints absent here, so it is not a counterexample to this statement.

The [balanced graph-decomposition result of Feige and Singh](https://www.microsoft.com/en-us/research/wp-content/uploads/2008/09/edgecoloring.pdf) obtains unweighted degree-control bounds for freely partitioning graph edges. Encoding each source state as an item adds the constraint that every color receive exactly one state from each source; endpoint weights may also differ. The graph-edge theorem does not enforce that source/color permutation constraint.

Threshold decomposition of each coordinate cannot be applied independently: the same `pi_e` must serve both endpoint coordinates and all thresholds. Already for one two-state source `(1,0),(0,1)`, the two endpoint coordinate orders are opposite. Independent threshold or endpoint colorings can demand inconsistent state assignments. This identifies a consistency gap in that route, not a counterexample to range two.

The signed-trail proof uses exact cancellation of `+1` and `-1` incidences at internal vertices. For arbitrary real source states, opposite-sign endpoint differences need not have equal magnitudes; negating a trail may alter the load differences at every internal vertex. Neither this proof nor the literature results above establishes weighted range two. The unrestricted exact-stock arbitrary-linked-star integer transfer remains open.

The most direct weighted extension of the potential proof is **false**. Let the row set consist of a root `r` and the `512` vertices of the nine-dimensional cube `Q_9`. For each cube vertex `v`, make one port column with coefficients `5/1024` at `r` and `+1` at `v`. For each cube edge `uv`, make one column with coefficient `-1/9` at both `u,v`. Every column has two nonzero entries in `[-1,1]`. Signing all columns `+1` gives root discrepancy `5/2`, every cube discrepancy zero, and squared Euclidean energy `25/4`.

For an arbitrary signing, denote the port signs by `p_v` and cube-edge signs by `q_e`. At cube vertex `v`, the discrepancy is `(1/9) sum_{e incident v}(p_v-q_e)`, so its squared discrepancy is `4 k_v^2/81`, where `k_v` is the number of incident cube edges whose sign differs from `p_v`. By negating all signs if needed, let `S={v:p_v=-1}` have size `s<=256`. Each cube edge crossing `S` causes a mismatch at at least one endpoint, hence `sum_v k_v^2 >= sum_v k_v >= |delta(S)| >= s`; the last inequality is the standard cube edge-expansion bound, obtainable from the cube Laplacian spectral gap two. The cube energy is therefore at least `4s/81`. The root discrepancy is `5/2-5s/512`, whose squared energy saves at most `25s/512` relative to `25/4`. Since `4/81 > 25/512`, every `s>0` gives total energy strictly larger than `25/4`. If `s=0`, minimizing cube energy forces all `q_e=+1`. Thus the only global minima, up to negating all signs, have root discrepancy `5/2>2`.

This is a counterexample to the **global quadratic-minimizer criterion**, not to existence of some signing with discrepancy at most two. Indeed, set port signs according to the first cube coordinate, so the root discrepancy is zero; match the edge sign to the common port sign on each of the eight other cube directions, and assign first-direction edges arbitrarily. Each cube vertex then has at most one mismatched incident edge, giving discrepancy at most `2/9`. A weighted range-two theorem, if true, needs another potential or an exchange argument not requiring a globally minimum quadratic signing.

## Audited real-weight two-color lemma and remaining compatibility gap

For any real matrix `A` with at most two nonzero entries per column, each of absolute value at most one, and any starting vector `x^0 in [-1,1]^m`, there is a sign vector `s in {-1,1}^m` with `|A(s-x^0)| <= 2` in every row. In particular, fixing any two colors `c,d` in the source-permutation problem and allowing only their states to swap, some choice of swaps makes `|L_vc-L_vd| <= 2` at **all** hubs. This is a theorem about one selected color pair, not simultaneous range two for `N>=3`.

Proof of the matrix lemma: keep a set of live coordinates, initially all, and a set of active rows having at least two live nonzero coordinates. Preserve `Ax` on every active row while moving `x` inside `[-1,1]^m`; rows with at most one live coordinate are released permanently. If the number of active rows is smaller than the number of live coordinates, their homogeneous system has a nonzero kernel vector. Move along one direction until a live coordinate reaches `-1` or `+1`, fix it, and repeat. At release, a row's value still equals its starting value, and only its one remaining live coordinate can subsequently change; its final error is therefore at most two. If the number of active rows equals the number of live coordinates, double-count live incidences. Each active row has at least two, and each live column has at most two, so equality forces exactly two live incidences in every active row and every live column. Round each remaining coordinate to its nearest sign; each changes by at most one, and hence each active row changes by at most two. The same released-row bound applies. This terminates and proves the claim. Zero columns may simply be fixed at either sign.

An initially proposed variant that preserved only rows having at least three live columns was **invalid**: a row released with two live coordinates may later incur total error approaching four. The threshold-two argument above is essential.

The lemma gives no monotone improvement of a global multi-color potential. The nine-cube example above is already a counterexample to using `sum_v (L_vc-L_vd)^2`: its all-positive signing is a global quadratic minimum despite a root gap of `5/2`, although another signing has every gap at most two. Moreover, repairing pair `c,d` can change their loads relative to any third color. We have no invariant that makes successive pair repairs converge to simultaneous range two or the weaker per-hub overload `N/2`.

The August 2026 [Bérczi–Liu–Reis–Tarnawski paper](https://arxiv.org/html/2608.13983), Section 8, explicitly leaves weighted equitability for a matroid base partition under *multiple* weight rows of bounded column sparsity open, even for existence of a bound depending only on the sparsity. Our source states form a partition matroid with two hub-weight rows per state and the extra restriction that all states of one source share the same pair of hub supports. Thus their question contains a relaxation of the setting here; their single-weight theorem does not yield the desired simultaneous range-two statement.
